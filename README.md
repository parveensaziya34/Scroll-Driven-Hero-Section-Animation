# ITZFIZZ Scroll-Driven Hero

Responsive React hero page with a GSAP intro and a scroll-scrubbed car journey.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The build uses the `/Scroll-Driven-Hero-Section-Animation/` asset base for GitHub Pages. Configure the repository's Pages source to **GitHub Actions** to publish from the `main` branch.

The car image is loaded from the reference project's public image URL.
