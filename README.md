# ITZFIZZ Scroll-Driven Hero

Responsive React hero page with a GSAP intro and a scroll-scrubbed car journey.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The build uses the `/fizz/` asset base for GitHub Pages. To publish, create a GitHub repository named `fizz`, push this project to its `main` branch, then configure the repository's Pages source to **GitHub Actions**.

The car image is loaded from the reference project's public image URL.
